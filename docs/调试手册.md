# 女性安防系统 — 调试手册 (Phase 2)

当前阶段未接模块: 指纹(ZW101)、语音(JQ8900)、WiFi(ESP8266)。

---

## 第1步：上电第一眼

1. OLED 显示 `OLED OK` 停留 2 秒
2. 然后进入监控页 `- SAFETY MON -`
3. 蜂鸣器不响、RGB 不亮

异常：
- OLED 不亮 → 查 PB8/PB9 接线、模块供电
- 蜂鸣器长鸣 → 查 PA5 极性 (低电平触发/高电平触发)
- 无显示但背光亮 → 查 I2C 地址 (0x78)

---

## 第2步：按键测试

| 按键 | 监控页 | 设置页 |
|------|--------|--------|
| KEY1 (PB13) | 翻页 | 翻页回监控页 |
| KEY2 (PB14) | 布防/撤防 | 光标下移 (6 个位置) |
| KEY3 (PB15) | 无操作 | 调值/翻方向 |

正常：按键有反应、页面切换不闪烁。

---

## 第3步：界面确认

一共 3 个界面，用 KEY1 切换：

**监控页**: `ARM: ON/OFF` + 传感器实时数据 (T/S/G/F/P/R)
**设置页**: 阈值列表 + `[+]/[-]` 方向指示，KEY2 移光标，KEY3 调值
**报警页**: 仅在布防+触发报警时自动弹出，KEY1 撤防退出

---

## 第4步：传感器测试

### DHT11 (PA12)
- 监控页看 `T` — 手捂 DHT11 10~20秒，数值缓慢变化
- 不变 → 查供电、数据线

### MQ-2 / MQ-7 (PA0 / PA1)
- 监控页看 `S`(烟雾) 和 `G`(CO)
- 打火机放气靠近，数值上升
- 不变 → 查 AO 接线、模块供电、需要预热 48h

### 火焰传感器 (PA4 AO / PA11 DO)
- 监控页看 `F` — 打火机在传感器前晃，数值变化
- 不变 → 查 DO/AO 接线

### PIR (PA8)
- 监控页看 `P` — 人在传感器前移动，P 变 1
- 不变 → 查供电、预热时间

### LD2410C 雷达 (PA9/PA10 USART1)
- 监控页看 `R` — 人在雷达前走动，R 变 1
- 不变 → 查波特率 25600、TX/RX 交叉

---

## 第5步：报警测试

前提：KEY2 切换到 **ARM: ON**（布防状态）。

### 火灾报警
- 打火机靠近火焰传感器 + 烟雾传感器 → 累计触发 → OLED 弹报警页
- 蜂鸣器响、RGB 红灯

### 入侵报警
- 人在 PIR + 雷达前持续移动 → 累计触发 → OLED 弹报警页
- 蜂鸣器响、RGB 蓝灯

### 解除报警
- 在报警页按 KEY1 → 自动撤防 → 返回监控页

### 撤防不报警
- KEY2 切换到 ARM: OFF → 所有传感器只显示数据，不触发任何报警

---

## 第6步：阈值调节

1. KEY1 切到设置页
2. KEY2 移到要调的阈值 (F/火, T/温, S/烟, G/气, PIR, 方向)
3. 光标在方向位时 KEY3 翻 [+]/[-]
4. 光标在阈值位时 KEY3 加减数值
5. 切回监控页，新阈值立即生效

---

## 第7步：常见异常

| 现象 | 先查 |
|------|------|
| OLED 不亮 | PB8/PB9, 供电 |
| 蜂鸣器一直响 | PA5 极性, CubeMX 初始电平 |
| 按键没反应 | PB13/14/15, 上拉 |
| 传感器全是 0 | DMA/ADC 是否启动 |
| 布防后不报警 | 阈值太高, 调低 |
| 撤防后还报警 | state_result 未清, 重置 |
| 系统频繁重启 | 看门狗超时, 查心跳 |

---

## 第8步：正常状态速查

**撤防 (ARM: OFF)**
- OLED 监控页正常显示
- 蜂鸣器不响、RGB 灭
- 按键可切页

**布防 (ARM: ON)**
- OLED 监控页正常显示
- 传感器触发 → 报警页弹出
- 蜂鸣器响 + RGB 亮

**设置页**
- KEY2 移动光标
- KEY3 调值
- 阈值生效
