## 3. 传感器采样与滤波算法

### 3.1 卡尔曼 + EWMA 联合滤波 (待实现)

对 MQ-2 烟雾和 MQ-7 CO 的 ADC 采样值做两级平滑:

```
ADC 原始值 → Kalman 滤波 (抑制突变) → EWMA 指数加权 (去除毛刺) → 稳定值
```

- **Kalman**: 对传感器物理过程建模, 预测下一时刻值, 与实际采样值融合
- **EWMA**: `S_new = α × S_old + (1-α) × V_new`, α≈0.3~0.4
- 作用: 消除 ADC 抖动、供电噪声、瞬时干扰

### 3.2 EWMA 入侵置信度平滑 (待实现)

对入侵融合分值做平滑:

```
入侵原始分 → EWMA(filter=40) → 平滑后的入侵置信度
```

- 避免 PIR 瞬时触发一次就报警
- 雷达信号抖动被平滑掉

### 3.3 当前实现状态

Phase 2 当前代码中: ADC 采样由 TIM3+DMA 硬件完成, 每个通道 100ms 采一次,
SensorTask 直接读取 DMA 缓冲区原始值传递给 SecurityTask。
卡尔曼/EWMA 滤波待 Phase 2 优化时加入。

## 4. 火灾判定算法

### 4.1 设计权重

| 传感器 | 权重 | 说明 |
|--------|------|------|
| 温度 (DHT11) | 70 | 室内异常升温是火灾最可靠特征 |
| 烟雾 (MQ-2) | 55 | 烟雾浓度上升 |
| CO/气体 (MQ-7) | 40 | 可燃气体/CO 检测 |
| 火焰传感器 | 5 | 辅助参考(静态不稳定, 低权) |

### 4.2 判定条件 (满足任一)

1. 温度超阈值
2. 烟雾 + 温度 同时超阈值
3. 烟雾 + 气体 同时超阈值
4. 温度 + 气体 同时超阈值
5. 加权总分 ≥ 60

### 4.3 当前实现

Phase 2 当前代码使用简化版: 四项独立投票(40+30+20+10), ≥30 预警 ≥60 报警。
阈值可在 OLED 设置页实时调节。

## 5. 入侵判定算法

### 5.1 设计权重

| 传感器 | 权重 | 说明 |
|--------|------|------|
| PIR 红外 | 70 | 人体检测主要来源 |
| 雷达 (LD2410C) | 10 | 辅助参考(室内多径干扰) |

### 5.2 判定流程

```
PIR触发(70) + 雷达目标(10) → EWMA平滑(filter=40) → 稳定置信度
稳定置信度 ≥ 60 → 入侵报警
```

### 5.3 当前实现

Phase 2 使用简化版: PIR+雷达有人=30, 距离<200cm=15, 运动=25, 静止=50, ≥60 报警。

## 6. 状态机设计

```
撤防(DISARMED) ──(布防按键)──→ 布防(ARMED)
     │                              │
     │                         (触发判定)
     │                              ↓
     │                         预警(WARNING)
     │                         (连续3次确认)
     │                              ↓
     │                         报警(ALARM)
     │                         (蜂鸣器+RGB+语音)
     │                              │
     └────────(撤防按键)────────────┘
```

- 撤防态: 只显示数据, 不触发任何报警
- 布防态: 检测火灾+入侵
- 预警态: 连续 3 次判定≥1 转报警, 连续安全转布防
- 报警态: 保持, 等撤防指令解除

## 7. 声光报警策略

| 报警类型 | 蜂鸣器 | RGB | 语音 |
|----------|--------|-----|------|
| 火灾预警 | — | — | — |
| 火灾报警 | 长鸣 | 红色常亮 | IO1 播报"火灾" |
| 入侵预警 | — | — | — |
| 入侵报警 | 短促鸣叫 | 蓝色闪烁 | IO2 播报"入侵" |
| 火灾+入侵 | 长鸣(火优先) | 红色常亮(火优先) | IO1 播报 |
| 正常 | 不响 | 绿色常亮 | 不触发 |
