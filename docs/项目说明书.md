## 3. 传感器采样与滤波算法

### 3.1 卡尔曼 + EWMA 联合滤波 (待实现)

对 MQ-2 烟雾和 MQ-7 CO 的 ADC 采样值做两级平滑:

```
ADC 原始值 → Kalman 滤波 (抑制突变) → EWMA 指数加权 (去除毛刺) → 稳定值
```

- **Kalman**: 对传感器物理过程建模, 预测下一时刻值, 与实际采样值融合
- **EWMA**: `S_new = α × S_old + (1-α) × V_new`, α≈0.3~0.4

`S_new` — 本次滤波后的输出值（发给 SecurityTask）

`S_old` — 上一次滤波后的值（用 static 变量保存）

`V_new` — 本次传感器原始读数

`α` — 平滑系数，0~1，越大越平滑但响应越慢

- 作用: 消除 ADC 抖动、供电噪声、瞬时干扰

### 3.2 EWMA 入侵置信度平滑 (待实现)

对入侵融合分值做平滑:

```
入侵原始分 → EWMA(filter=40) → 平滑后的入侵置信度
```

- 避免 PIR 瞬时触发一次就报警
- 雷达信号抖动被平滑掉

### 3.3 当前实现状态 (2026-08-04 更新)

#### 已实现：中值滤波 + EWMA 组合

SensorTask 的 `publish_sensor_data()` 中已对 4 路模拟量加入软件滤波:

| 传感器     | 滤波方案           | α 值 | 说明                         |
| ---------- | ------------------ | ----- | ---------------------------- |
| 火焰 (AO)  | 中值(窗口3) + EWMA | 0.70  | 先剔除单采样尖峰, 再指数平滑 |
| MQ-2 烟雾  | EWMA               | 0.85  | 气体变化慢, 强平滑           |
| MQ-7 CO    | EWMA               | 0.85  | 气体变化慢, 强平滑           |
| DHT11 温度 | EWMA               | 0.90  | 温度变化极慢, 最强平滑       |

#### 火焰传感器滤波效果 (STAR 数据)

| 指标               | 滤波前                          | 滤波后                                 |
| ------------------ | ------------------------------- | -------------------------------------- |
| 无火焰状态数值范围 | 0 ~ 300 (剧烈跳动)              | 155 ~ 175 (稳定)                       |
| 单次采样尖峰       | 直接传给 SecurityTask, 引发误报 | 中值滤波直接丢弃                       |
| 响应延迟           | 0 (原始值)                      | 约 300ms (中值3窗口×100ms + EWMA滞后) |

> **解读**: 火焰传感器 (红外光电管) 对室内灯光、自然光变化敏感,
> 原始 ADC 值在无明火时也会大幅抖动。
> 加入中值+EWMA 两重滤波后, 无火基线稳定在 155~175,
> 为后续 `th_fire` 阈值标定提供了可靠基础。

- 卡尔曼滤波: STM32F103 算力受限, EWMA 已满足需求, 不再引入
- 入侵置信度 EWMA 平滑: 待实测后按需加入

## 4. 火灾判定算法

### 4.1 设计权重

| 传感器         | 权重 | 说明                         |
| -------------- | ---- | ---------------------------- |
| 温度 (DHT11)   | 70   | 室内异常升温是火灾最可靠特征 |
| 烟雾 (MQ-2)    | 55   | 烟雾浓度上升                 |
| CO/气体 (MQ-7) | 40   | 可燃气体/CO 检测             |
| 火焰传感器     | 5    | 辅助参考(静态不稳定, 低权)   |

### 4.2 判定条件 (满足任一)

1. 温度超阈值
2. 烟雾 + 温度 同时超阈值
3. 烟雾 + 气体 同时超阈值
4. 温度 + 气体 同时超阈值
5. 加权总分 ≥ 60

### 4.3 当前实现

Phase 2 当前代码使用简化版: 四项独立投票(40+30+20+10), ≥30 预警 ≥60 报警。
阈值可在 OLED 设置页实时调节。

## 5. 入侵判定算法

### 5.1 设计权重

| 传感器         | 权重 | 说明                   |
| -------------- | ---- | ---------------------- |
| PIR 红外       | 70   | 人体检测主要来源       |
| 雷达 (LD2410C) | 10   | 辅助参考(室内多径干扰) |

### 5.2 判定流程

```
PIR触发(70) + 雷达目标(10) → EWMA平滑(filter=40) → 稳定置信度
稳定置信度 ≥ 60 → 入侵报警
```

### 5.3 当前实现

Phase 2 使用简化版: PIR+雷达有人=30, 距离<200cm=15, 运动=25, 静止=50, ≥60 报警。

## 6. 状态机设计

```
撤防(DISARMED) ──(布防按键)──→ 布防(ARMED)
     │                              │
     │                         (触发判定)
     │                              ↓
     │                         预警(WARNING)
     │                         (连续3次确认)
     │                              ↓
     │                         报警(ALARM)
     │                         (蜂鸣器+RGB+语音)
     │                              │
     └────────(撤防按键)────────────┘
```

- 撤防态: 只显示数据, 不触发任何报警
- 布防态: 检测火灾+入侵
- 预警态: 连续 3 次判定≥1 转报警, 连续安全转布防
- 报警态: 保持, 等撤防指令解除
